# Our Hermes Agent Plugins

Shared Hermes Agent plugins maintained as separate installable directories.

## Plugins

| Plugin | Description |
|---|---|
| [`telegram-skill-review`](./telegram-skill-review/) | Sends autonomous pending skill proposals to separate Telegram topics and applies delayed Approve or Reject decisions without an LLM call. |

Each plugin directory contains its own `plugin.yaml`, implementation, tests, configuration instructions, and operational notes.
